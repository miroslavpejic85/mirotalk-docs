Three ways to build

Start with how your source code is distributed and whether end users pay. That usually makes the right choice straightforward.

Open source

AGPLv3

For projects that keep their MiroTalk-based source code public.

  • Free and open-source use
  • Modification and forking allowed
  • Modified source must remain public
  • Changes must be clearly documented
Read the AGPLv3 terms →
Private, non-commercial

Regular

For a closed-source personal project that does not charge end users.

  • Keep your source code private
  • Rebrand logo, name, and description
  • Use in one end product
  • Direct support included
See regular prices →
Private, commercial

Extended

For a closed-source commercial project that charges end users.

  • Keep your source code private
  • Rebrand logo, name, and description
  • Monetize one end product
  • Direct support included
See extended prices →
Quick rule

If users pay to access your closed-source product, choose Extended. If they do not, Regular is usually the right private-use license.
