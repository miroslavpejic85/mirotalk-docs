## Common questions

### Is MiroTalk Ultimate a subscription?

The published Regular and Extended purchase paths are one-time license purchases. Infrastructure, domains, external services, maintenance, and other operating costs are separate.

### Can I customize and rebrand the applications?

The current offer includes source code and describes customization and rebranding rights. Confirm the permitted use, distribution, and number of end products in the applicable license before purchase.

### Can all seven applications run on one server?

They can share infrastructure in some deployments, commonly using separate subdomains and reverse-proxy routes. Whether one server is appropriate depends on load, media architecture, resilience, storage, and enabled services.

### Can I charge end users?

The Extended path is intended for eligible end products that charge end users. Review the complete terms because the commercial model and product structure can affect which license applies.

### Where can I get deployment or customization help?

[Enterprise services](../enterprise/index.md) covers architecture, deployment, integration, customization, and operational enquiries. You can also [contact MiroTalk by email](mailto:miroslav.pejic.85@gmail.com).
