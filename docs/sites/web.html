Common Questions

MiroTalk WEB FAQ

Are the video applications included?
No. P2P, SFU, C2C, BRO, and CME are sold separately. WEB connects the applications you purchase and configure.
Can I build a video SaaS?
Yes. WEB includes user accounts, scheduling, subscription plans, and customer management. Use the CodeCanyon license appropriate to your monetization.
Can multiple apps run on one server?
Yes. Subdomain deployment is supported, subject to available resources and expected traffic.
Can I white-label WEB?
Yes. Full source code is included for branding and custom development.
