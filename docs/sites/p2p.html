Common Questions

MiroTalk P2P FAQ

Is MiroTalk P2P subscription-based?
No. It is a one-time CodeCanyon purchase. You remain responsible for hosting and infrastructure.
Does P2P need a media server?
Direct calls do not require one. A configured TURN server can relay encrypted media when direct connectivity is unavailable.
Can I white-label it?
Yes. Full source code is included for branding and custom development.
What determines practical room size?
Participant devices, upload bandwidth, network conditions, and media settings determine practical P2P room capacity.
