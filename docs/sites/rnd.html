Simple Session Flow

Join Queue, Match, Chat, Repeat

Participants enter a waiting queue, get matched into one-to-one sessions, and can continue or skip to a new match.

1. Join

User opens the app and enters the match queue.

2. Match

Server pairs two participants into a session.

3. Chat

WebRTC video/audio starts in the browser.

4. Next

Either participant can skip and rejoin matching.

Deployment Requirements

Run RND on Your Infrastructure

Set up with Node.js, PM2, or Docker and place it behind HTTPS for stable browser camera/microphone permissions.

  • Ubuntu 22.04/24.04 LTS recommended
  • Node.js 24+ or Docker
  • Domain, DNS, and SSL
  • TURN server recommended
  • PM2 for process supervision
