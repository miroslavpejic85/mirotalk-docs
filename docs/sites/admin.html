Common Questions

MiroTalk Admin FAQ

Does Admin host video meetings?
No. Admin is an operational control plane for deployed MiroTalk services. It does not provide meeting rooms or process media.
Can it manage services on another server?
Yes. SSH mode is designed for remote hosts. Pin the host fingerprint and use credentials with only the permissions required for management.
Can I use Admin with Docker?
Yes. Docker mode can manage sibling containers when the deployment grants access to the Docker daemon. Treat that access as highly privileged.
Where should I start?
Use the quick-start guide to evaluate Admin locally, then follow the self-hosting guide to configure HTTPS, credentials, and production access controls.
