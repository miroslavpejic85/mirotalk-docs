Common questions

Choose with confidence

Can I keep my source code private?
Yes. Both the Regular and Extended licenses allow you to keep your source code private.
Which license allows me to charge users?
The Extended license is intended for an eligible closed-source end product where end users can be charged for access. Confirm your exact use case against the complete terms.
Does one purchase cover multiple products?
Yes, when purchasing MiroTalk ULTIMATE, which includes all MiroTalk projects. Purchases of individual products cover only that product.
Can I rebrand MiroTalk?
Yes. Both the Regular and Extended licenses allow you to rebrand the product name, logo, and description.
Where can I read verified customer reviews?
