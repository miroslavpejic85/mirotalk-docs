Common Questions

Call-Me FAQ

Does the person receiving a call need an account?
No. A guest can open a shared call link in a supported browser without an account or dedicated app.
Are calls peer-to-peer?
Media uses direct WebRTC connections when possible. A configured TURN server can relay encrypted media when network conditions require it.
Can I white-label it?
Yes. Full source code is included for branding and custom development.
Is Call-Me subscription-based?
No. It is a one-time CodeCanyon purchase. Hosting, bandwidth, and TURN costs remain your responsibility.
