## Embed MiroTalk

MiroTalk communication products can be embedded with iframes, direct links, and product-specific APIs. Camera, microphone, display capture, and other browser permissions must be granted explicitly by the host page.

[Open the quick iframe guide](../utility/quick-custom-integration.md){ .md-button .md-button--primary }
